Three steps

How it works

The software keeps the file in order. The auditor is the one who decides.

  1. 01

    Open the engagement

    A credentialed auditor opens one independent test and invites the broker-dealer. There is no public sign-up.

  2. 02

    Collect the program file

    The firm answers a short applicability questionnaire and uploads the documents the checklist requests. If a file needs to be replaced, the note stays at the document level: unreadable, wrong period, wrong document, or missing pages.

  3. 03

    Review and sign

    The auditor reviews the file. A finding is accepted only with a document and a page. Kien can prepare an unsigned draft. The auditor signs the report.

Benefits

  • Scoped to Rule 3310

    The engagement is the independent AML test for a broker-dealer, not a general file room.

  • A checklist the firm can finish

    Requests, applicability questions, and uploads stay in one list, including what is still open.

    The client view shows intake status. It does not show audit findings.

    The software does not approve a finding or mark a report signed. That stays with the credentialed auditor.
