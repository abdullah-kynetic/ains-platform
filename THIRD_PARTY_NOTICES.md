# Third-party design and implementation notices

These MIT sources were inspected before adaptation. Components are adapted to Kien Solutions React/Next routing, accessible native controls and FastAPI cookie sessions; no upstream authentication integrations are included. Entendre is a general visual direction only; no wording, logos or code were copied.

Source: https://github.com/Kiranism/next-shadcn-dashboard-starter

Revision: 9084ffd954d24591d9b1d279c4b18e119b02b34e

### Layout preview adaptation (`feat/shadcn-layout`)

The shared cards, buttons, badges, tables, tabs and inputs additionally adapt
the geometry of this starter's UI primitives. Portal pages and the resizable
sidebar use its compact spacing, icon rail, group labels, and frosted navigation
header. Kien retains its palette, font stack, theme controller, authentication
and workflows; no starter authentication or demo features are included.
